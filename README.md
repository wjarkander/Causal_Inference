# Causal_Inference

## Which Variables Should You Control For?

Assignment by William Jarkander, Thauri Dattadeen and Isac Sandberg, May 2026.

Folder: `Which_Variables_Should_You_Control_For/` (report and R code)

### Abstract

In Causal Inference, the selection of covariates plays a crucial role in determining the causal effect. In this simulation study on observational data, we review the effect of variable selection using different types of covariates, to effectively answer the question "Which variables exactly should you control for?"
